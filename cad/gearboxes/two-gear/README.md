# Two-gear gearbox

Four top-down placements: base, gear 1, gear 2, and drop-on cover. The gears are identical; print the gear twice.

- `base.*` — plate with integral tapered shafts
- `gear.*` — coarse spur gear with standardized grasp tab
- `cover.*` — one-piece drop-on cover
- `assembled.*` — visual reference only

The STL files are convenient for simulation; 3MF files are preferred for printing and unit preservation.
