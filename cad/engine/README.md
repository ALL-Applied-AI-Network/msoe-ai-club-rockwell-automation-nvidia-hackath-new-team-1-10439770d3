# Inline-four engine demonstrator

Top-down assembly sequence:

1. block;
2. crankshaft;
3. rods 1–4;
4. drop-on cover;
5. cylinder head; and
6. pistons 1–4.

The rods are inserted before the cover and head so their grasp tabs retain a clear vertical approach corridor.

Individual simulation-ready STLs and source 3MF exports are included. `asset_manifest.json` records part hashes and geometry checks from the validated simulation package. The physical trial used a 220% slicer scale; repository geometry remains nominal.
