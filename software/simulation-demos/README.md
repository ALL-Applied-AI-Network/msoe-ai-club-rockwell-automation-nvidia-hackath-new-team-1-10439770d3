# Isaac Sim assembly demonstrations

These folders preserve the scripts, compact reports, and representative renders for three top-down assembly tasks:

- [`gearbox`](gearbox/) — base, two gears, and cover;
- [`engine-block`](engine-block/) — block, crankshaft, cover, head, four rods, and four pistons; and
- [`brewers-badge`](brewers-badge/) — stand, base, emblem, detail carrier, and nameplate.

The corresponding printable geometry is in [`cad`](../../cad/README.md). Asset paths in the original run scripts may need to be redirected to the repository CAD folders.
